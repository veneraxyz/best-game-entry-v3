EMBERFALL KEEP — hold the last lighthouse through five nights. By day, build traps on the grid around the keep: spike pits, ember braziers, frost wards, lightning rods and ballistas. By night, fight beside them with a lantern-flail and a dash, while the lighthouse beam sweeps the dark and burns the shadows caught in it. Six enemy kinds, two bosses, eight boons to draft, combos up to x8 — survive until dawn.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play game/index.html in desktop Chrome. No build step, no network: the game is plain static files under game/.
